Overview

U College is a comprehensive virtual campus platform designed to streamline student registrations, grade management, admissions, and more. I was responsible for developing the backend system and designing the database architecture, working within a team of four using Agile methodology (Scrum) with 2-week sprints.

Web URL:
https://u-college-frontend.vercel.app

Technologies Used

Backend: Node.js (Express), TypeScript
Database: PostgreSQL
Hosting: Railway
Authentication: JWT login system
File Storage: Cloudinary
Frontend: React.js (for front-end integration)

Key Features

Backend Functionality (Node.js with Express):

JWT Login System: Secure user authentication ensuring safe access for students, faculty, and administrators.
Student Registration: Allows students to register, update profiles, and manage their courses.
Admissions Management: Admins can handle student applications, track status, and send notifications.
Grade Management: Admins and professors can input, update, and manage student grades.
Campus Resources: Includes access to virtual campus tools, schedules, and materials.
Cache System: Uses Redis for caching frequently requested data to enhance performance.
Database Design and Hosting (PostgreSQL on Railway):

Entity-Relationship Model to SQL Script: Designed the database schema, including tables for users, courses, registrations, grades, and more.
Triggers for Registration and Grades Flow: Ensures smooth interactions between student registrations and grade management.
Hosted on Railway: The PostgreSQL database is hosted on Railway, ensuring easy scalability and management.
